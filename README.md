# 📸 PhotosSync — Sync Google Photos

Application Android native (Kotlin + Gradle) qui synchronise TOUTES vos photos/vidéo vers un autre compte Google Photos.

## ✅ Fonctionnalités
- 📷 Surveille Appareil photo, Snapchat, WhatsApp, captures... TOUT
- 🔄 Service en arrière-plan en temps réel
- ☁️ Envoi vers compte Google Photos séparé
- 📲 APK compilée automatiquement sur GitHub

## 📥 Télécharger l'APK
Allez dans **Actions → Build PhotosSync APK → Artifacts → PhotosSync-APK**

## 🔑 Configuration
1. Déposez `credentials.json` à la racine du stockage
2. Ouvrez l'appli → Connecter Google → Démarrer
