# 📸 PhotosSync — Sync Google Photos

Application Android qui synchronise automatiquement TOUTES vos photos et vidéos vers un autre compte Google Photos.

## 📥 Télécharger l'APK
Allez dans **Actions → Build APK → Artifacts → PhotosSync-APK**

## 🔑 Configuration
1. Déposez `credentials.json` à la racine du stockage de votre téléphone
2. Ouvrez l'application
3. Cliquez sur **Connecter Google** → suivez le lien
4. Cliquez sur **Démarrer la synchro**

## 📋 Surveille
- 📷 Appareil photo
- 📱 Snapchat, Instagram, TikTok, WhatsApp, Telegram...
- 🖼️ Captures d'écran
- 📥 Téléchargements
- 🌍 TOUT le téléphone
